# 数据对比验收用例

- [ ] baseline 和 target 完全一致时，一致数正确，不一致和缺失为 0。
- [ ] 两侧都有 key 但比较字段不同，不一致数正确，明细展示差异字段、baseline 值、target 值、差值和变化率。
- [ ] key 只存在于 baseline 时，计入 target 缺失，并可点击查看具体明细。
- [ ] key 只存在于 target 时，计入 baseline 缺失，并可点击查看具体明细。
- [ ] 配置分组列后，每个分组独立统计一致、不一致、缺失和一致率。
- [ ] 配置数值容差后，容差内判定一致，容差外判定不一致。
- [ ] SQL 使用宏变量切换版本时，baseline/target 宏分别生效。
- [ ] SQL 为复杂 JOIN 或聚合结果时，只按输出列配置 key、分组和比较列。
- [ ] 重复 key 时，后端拒绝运行并返回清晰错误。
- [ ] 非法宏变量沿用现有安全校验并拒绝执行。
- [ ] 超过最大对比行数时，后端中止并提示缩小 SQL 范围。
- [ ] 保存、更新、删除配置后刷新页面仍可复用。
- [ ] 汇总导出和明细导出 Excel 可打开，列和值正确。
