# 数据对比需求说明

## 目标

新增独立“数据对比”栏目，用于对同一 SQL 在 baseline 与 target 两组宏参数下的输出结果进行对账。第一版聚焦结果集级别对比，不复用 Saved Query，也不进入 Dashboard Widget。

## 功能范围

- 支持选择数据源、编写原始 SQL、配置 baseline/target 名称与宏变量。
- 支持配置主键列、分组列、对比标准和最大对比行数。
- 支持严格相等、数值绝对容差、数值百分比容差三种比较方式。
- 支持保存、更新、删除独立对比配置。
- 支持运行后输出分组汇总，并点击一致、不一致、baseline 缺失、target 缺失数量查看对比明细。
- 支持汇总表与当前明细导出 Excel。

## 非目标

- 不支持多个 Saved Query 之间的任意对比。
- 不支持超过 baseline/target 两组数据的多版本对比。
- 不支持字段名映射，默认两侧 SQL 输出列名一致。
- 明细弹窗展示对比结果明细，不继续追溯原始底表 Drill-through。
